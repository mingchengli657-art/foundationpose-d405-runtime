# 已知限制

- 首帧需要手动圈选，属于已知模型的单物体跟踪，不是任意物体分类检测。
- `recovery_required` 仅在状态变化时发布，未配置持久化状态。后启动的订阅者可能不知道已有恢复状态，应同时检查位姿时间戳。
- IPC 目录仅支持一对 ROS I/O 与 worker；ROS I/O 启动会清理旧数据，不能单独无缝重启。
- 轴向锁定适用于示例的对称性假设，固定的是难以观测的旋转分量，不是测得真实 yaw。
- 深度门限、位姿跳变门限与恢复帧数是原设备经验参数，不能保证错误位姿全部被拒绝。
- 物体模型中心不是抓取点。CPU 测试通过不代表 GPU 推理、相机时间同步或抓取精度通过。
